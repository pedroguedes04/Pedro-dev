# Pedro.Dev — Portfólio Pessoal

Portfólio pessoal desenvolvido durante o **Work in Tech 2026**, com o objetivo de apresentar quem eu sou, minhas habilidades e os projetos que venho construindo como desenvolvedor.

![Pedro Guedes](./Guedes.jpeg)

## Sobre o projeto

Página web estática feita com **HTML, CSS e JavaScript puro**, sem frameworks. O site é dividido nas seguintes seções:

- **Hero** — apresentação com foto, nome, cargo e botão de contato
- **Sobre mim** — um breve resumo sobre minha trajetória como estudante de Engenharia de Software
- **Habilidades** — cards com as tecnologias que utilizo
- **Projetos** — carrossel com os projetos que desenvolvi

## Funcionalidades

- **Tema claro / escuro**: botão no cabeçalho que alterna o tema da página, trocando cores e a imagem de fundo
- **Carrossel de projetos**: navegação pelos cards com as setas `<` e `>`, voltando ao início ao chegar no fim
- **Efeitos de hover**: animações nos links do menu, nos botões e nos cards de habilidades
- **Rolagem suave** entre os cards do carrossel

## Tecnologias utilizadas

| Tecnologia | Uso |
|------------|-----|
| HTML5 | Estrutura e conteúdo da página |
| CSS3 | Estilização, layout com Flexbox, transições e tema escuro |
| JavaScript | Alternância de tema e controle do carrossel |

## Estrutura de arquivos

```
├── index.html      # Estrutura da página
├── style.css       # Estilos e tema escuro
├── script.js       # Interatividade (tema e carrossel)
└── *.png / *.jpeg  # Imagens, ícones e fundos
```

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/pedroguedes04/Pedro-dev.git
   ```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar nenhuma dependência.
